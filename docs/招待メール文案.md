# 招待メール文案（新規会員向け）

【 】の部分を差し替えてお使いください。Slack への招待を先に送る運用なら A、招待リンクをこのメールに同封する運用なら B が向いています。

---

## A. Slack の招待とは別に送る場合

**件名：** 【アクセルビジネスカレッジ】ようこそ！アプリの入り方をご案内します

【お名前】さん

アクセルビジネスカレッジ（ビジカレ）へのご入会、ありがとうございます。運営の二宮です。

ビジカレでは、メンバー同士のやりとりや勉強会の録画、イベントの日程調整などを、専用のアプリで行っています。まずは以下の3ステップでアプリに入ってみてください。

■ アプリに入る3ステップ
1. Slack の招待メール（別途お届けしています）から、Slack ワークスペース「アクセルビジネスカレッジ」に参加する
2. アプリ（ https://college.accel-dash.com/ ）を開いて「Slackアカウントでログイン」を押す
3. Slack の確認画面で「許可する」を押す → ホーム画面が開けば完了です

パスワードの登録は要りません。Slack のアカウントがそのままログインになります。

■ 画面つきの詳しい案内はこちら
https://college.accel-dash.com/welcome
入り方から最初にやること、うまく入れないときの対処までまとめています。

■ ログインしたら、最初にやってほしいこと
・プロフィールを書く（メンバー → 自分の名前 → プロフィールを編集）
・実務従事の更新期限を登録する（設定 → 実務従事の更新期限）
・チャットでひと言、自己紹介

■ うまく入れないとき
Slack からのメールが届かないときは迷惑メールフォルダをご確認ください。会社のメールアドレスだと届きにくいことがあります。それでも入れない場合は、このメールに返信いただければ対応します。

それでは、アプリでお会いできるのを楽しみにしています。

アクセルビジネスカレッジ 運営
二宮

## B. Slack の招待リンクを同封する場合

**件名：** 【アクセルビジネスカレッジ】ご入会ありがとうございます｜Slack とアプリへのご案内

【お名前】さん

アクセルビジネスカレッジ（ビジカレ）へのご入会、ありがとうございます。運営の二宮です。

ビジカレのやりとりは Slack と専用アプリで行っています。以下の順で進めてください。所要時間は5分ほどです。

1. Slack に参加する
　下のリンクから、Slack ワークスペース「アクセルビジネスカレッジ」に参加してください。
　【Slack招待リンク】
　※ Slack のアカウントをお持ちでない場合は、リンク先で作成できます。

2. アプリにログインする
　https://college.accel-dash.com/ を開き、「Slackアカウントでログイン」→ Slack の画面で「許可する」を押してください。パスワードの登録は要りません。

3. プロフィールを書く
　ログイン後、「メンバー」→ 自分の名前 →「プロフィールを編集」から、都道府県・所属・得意分野を書いてください。相談や紹介につながります。

画面つきの詳しい案内はこちらにまとめています。
https://college.accel-dash.com/welcome

スマホをお使いの方は、ブラウザの「ホーム画面に追加」をしておくと、アプリのように起動できて便利です。

■ うまく入れないとき
・Slack からのメールが届かない → 迷惑メールフォルダをご確認ください（会社のメールは届きにくいことがあります）
・それでも入れない → このメールに返信ください

アプリでお会いできるのを楽しみにしています。

アクセルビジネスカレッジ 運営
二宮
